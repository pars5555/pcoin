# List of fixed seed nodes for PCoin mainnet.
#
# These are the addresses a node falls back to when it has no peers in its
# addrman and DNS seeding produced nothing. Only nodes that accept inbound
# connections on a stable, hosted address belong here: unlike a DNS seed record,
# a hardcoded seed cannot be withdrawn without shipping a new release.
#
# Regenerate src/chainparamsseeds.h from this file with:
#   python3 contrib/seeds/generate-seeds.py contrib/seeds
# and keep only the chainparams_seed_main array. Mainnet is the only network
# with fixed seeds; the test networks call vFixedSeeds.clear().
#
# This file previously held Bitcoin's 2031 mainnet seeds on port 8333. Nothing
# read it, so it was harmless -- but it is the generator's input, so anyone who
# regenerated would have put Bitcoin nodes into PCoin's seed list.
#
# All three verified resolving from seed.pc.am and accepting tcp/9444 on
# 2026-08-04. Reverse DNS: two GCP, one Hetzner; all static addresses.
