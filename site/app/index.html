Why you cannot search for it

Typing “wPCN” into PancakeSwap finds nothing. Its token selector only searches curated token lists, and wPCN is on none of them — that takes a CoinGecko or CoinMarketCap listing first.

Until then the only ways in are the two links above, or pasting the contract address into PancakeSwap yourself and choosing Import:

0x290A5779a419Cb9cB22fa087CDD1CD16dA2D95F1

PancakeSwap will warn you that it is an unknown token. That warning is correct and you should read it — check the address against this one character by character, because anyone can deploy a token calling itself wPCN.

Read this first

The wPCN pool is small — a few hundred dollars moves it noticeably. It is a door, not a market, and it should not be read as a valuation. There is a limit on how much can be wrapped; the desk will say so.
